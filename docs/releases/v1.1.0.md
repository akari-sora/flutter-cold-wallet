# FCW v1.1.0 發版說明（測試簽章候選 r14）

標籤 `v1.1.0`（`master`）。APK 由 `7844740` 建置，應用版本 `1.1.0+3`；之後的 commit 只更新文件與截圖。

> 本文中的 commit SHA、標籤與候選編號指向私有存檔 repo；公開 repo 從單一起始 commit 開始，查不到這些 SHA 與標籤。

> **測試簽章與安全警告**
> 本次發布的 APK 為本機開發憑證簽署的測試建置（test builds），並非商店正式發版。
> 所有裝置驗證均在 Android 模擬器與測試資料（local Anvil／Bitcoin Core regtest）上執行，不涉及真實資產。
> 尚未完成實體相機對掃、實體 ARM64 手機簽署、真實裝置生物識別、S8、OKX 回傳路徑、實體裝置上的 bitcoind 流程，以及 iOS 執行（實機與模擬器）。請勿用於正式助記詞、真實資產或主網交易。

## 重點更新

- **視覺識別與設計系統（`2264535`、`58ed674`）**：Wallet 採用藍色系並跟隨系統淺色／深色主題；Vault 採用深綠色系並強制深色。兩 App 常駐獨立語意節點的角色徽章，統一間距、圓角、語意色調與系統等寬數字樣式。
- **所見即所簽審查與掃描回饋（`2264535`、`281eebb`、`58ed674`）**：Vault 交易審查頁將金額置頂，地址、路徑與摘要以等寬區塊完整展開；掃描器加入取景遮罩與角標；動態 QR 加入幀進度條；滑動確認改為膠囊軌道與等高進度填色；助記詞改為依寬度量測 1～3 欄的 tile（320dp、2x 字級下單字不截斷、不從中間斷開）。
- **可用性與無障礙修正（`0e07fad`、`281eebb`、`58ed674`）**：
  - EVM 建立待簽交易後自動捲動至 QR 並在建置中停用按鈕，防止連點重複建置。
  - BTC 建立新草稿時清空收款地址、金額與手續費。
  - 開啟掃描器前取消輸入框焦點，返回時不再自動跳出鍵盤。
  - Vault onboarding 錯誤就近顯示於操作按鈕旁並自動捲入畫面（含重複觸發相同錯誤）。
  - `FcwPanel` 改用 `Material` 恢復列表點擊漣漪與鍵盤焦點框（消除 Flutter 3.47 `ListTile` 背景斷言失敗）；展開區段頂部加上 16px 內距避免首個浮動標籤被裁切。
