# FCW v1.2.1 發版說明（測試網預覽版，候選 r20）

標籤 `v1.2.1`。候選 `r20` 對應 `70d56e8`，應用版本 `1.2.1+5`；相較 `64cb711` 的產品流程未變，後續 commit 只加入測試、文件與兩個 App 的啟動器圖示。

> 本文中的 commit SHA、標籤與候選編號指向私有存檔 repo；公開 repo 從單一起始 commit 開始，查不到這些 SHA 與標籤。

> **測試網預覽版與安全警告**
> 兩個 App 仍只支援測試網（EVM Sepolia 與本機開發鏈、Bitcoin regtest），不得用於正式助記詞、真實資產或主網交易。本專案未經第三方安全稽核。
> 本版起，GitLab 發布的 APK 以預定供 Google Play 採用的應用程式簽署金鑰（app signing key）簽署；Play Console 尚未完成設定及憑證核對，跨管道更新仍待驗證。安裝前請核對下方的憑證指紋。
> 從 `1.2.0` 以前的測試建置（本機開發憑證 `fde363be…` 簽署）升級時，簽章不同，系統會拒絕覆蓋安裝，需先解除安裝；Vault 的金庫檔會一併刪除，請先保留助記詞或加密備份。
> 所有裝置驗證都在 Android 模擬器與測試資料上執行；實體裝置驗收改由之後的 Google Play 封閉測試補足，尚未開始。OKX 簽章回傳與 iOS 執行也尚未驗證。

Phase 0 補完是分開的後續開發工作，不包含在本文的 r20 APK/AAB。後續工作以 Android 優先，分支範圍與未關閉驗收見 [Android 工作狀態](../ANDROID_STATUS.md)。

## 重點更新

- **新名稱與關於頁**：App 改名為 FCW Watch 與 FCW Vault（套件名稱不變）。兩個 App 新增「關於」頁，內含版本、原始碼網址、授權與完整隱私權政策（Vault 離線也能看）；首頁加上「未經第三方安全稽核，請先小額使用」（`34c4b14`、`2b5481b`、`d6a80b8`）。
- **節點網址規則**：`https://` 可用於任何主機；`http://` 只限 loopback 與私人網路。公開網路上的明文網址在輸入、儲存與送出前會檢查設定的初始網址；目前不檢查 HTTP 轉址目標。1.2.1 以前存下的這類網址通常會先停下並說明如何修改；若舊紀錄與目前 RPC 是不同網址，資料綁定檢查可能先拒絕重播。改用同一節點的允許網址後，舊紀錄在核對 Chain ID 後可以繼續查詢或廣播（`2fa5531`、`6726be2`、`d105315`、`ffdc5fb`、`4a72186`）。開發者使用 `adb reverse` 時，loopback 流量會轉送到電腦，並非只留在手機內。
- **節點資料揭露**：網址欄下方說明節點會收到地址、交易與 IP 位址；Bitcoin 另含帶擴充公鑰的 descriptor 與 RPC 帳號密碼（`7a6d75f`、`d05bbf9`）。
- **相機權限（`1.2.0` 已知問題）**：拒絕相機後不再反覆要求權限，Wallet 不會再被系統關閉；EVM 簽章掃描不再因權限視窗撤銷接收授權，允許後也不再出現 `controllerAlreadyInitialized`（`51b0842`、`58830cd`、`7fccd54`、`ec820c2`、`0017a12`、`5c266e9`、`fa404c4`、`cf4795a`、`1db5fc3`）。
- **送出狀態說明**：BTC 送出期間離開前景，改為與 EVM 相同的「結果待查」處理與說明；EVM 重送被撤銷時提醒先查詢；`sendrawtransaction` 收到 401／403 不再寫成「遭節點拒絕」（`5e9dd81`、`7779c8f`、`777a469`、`ebdec15`）。
- **隱私**：Wallet 移除 ML Kit 會傳送診斷資料給 Google 的元件（Vault 原本就已移除）（`76becf4`）。
- **建置與檢查**：新增跨平台的 Play AAB 檢查 `verify_play_bundle.py` 與 Android 工具定位 `android_sdk.py`；APK 檢查的憑證標示與 `python -O` 問題已修（`44e6595`、`6c2e026`、`e79de2f`、`58d3a43`、`851444a`）。
- **公開倉庫**：授權改為 AGPL-3.0-or-later（附 ML Kit／Play services 額外許可），移除內部工作資料，新增 `SECURITY.md` 與 `CONTRIBUTING.md`，截圖改用公開測試向量重拍。

完整清單見 [`CHANGELOG.md`](../../CHANGELOG.md)。

## 已知問題

- EVM 前一筆仍是「結果待查」或「廣播中」時，送出頁仍可用下一個 nonce 建立另一筆請求；目前沒有阻擋或「不要建立新請求」提示。若前一筆其實已送出，兩筆都會執行（P2，主網前必修）。
- 首次接收 EVM 簽章時到系統設定開啟相機再返回，這次接收授權已撤銷，需到交易紀錄找回原請求（畫面有說明）。
- 1.2.1 以前存下公開 `http://` 網址的 BTC 紀錄，被拒網址只在第一次開啟時顯示在欄位上；存檔一次後欄位變成空白，需重新輸入節點網址。只在同一個安裝留有舊紀錄時發生（從 `1.2.0` 測試建置升級必須先解除安裝）。
- RPC 網址政策只檢查設定的初始 URL，尚未檢查自動轉址目標；loopback 的「本機」說明也未涵蓋 `adb reverse` 會轉送到電腦的開發情境。
- 其他項目見 [`docs/REMAINING_WORK.md`](../REMAINING_WORK.md)。
